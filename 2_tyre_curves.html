Bandencurves

Twee bandenmengsels beschikbaar: soft en hard. Pure bandenprestatie, weergegeven als rondetijd op een verse, lichte wagen, tegen ronden gereden op die set banden. Soft is sneller voor een korte stint, hard houdt veel langer mee. Waar de curves elkaar kruisen zegt wanneer de ene sneller wordt dan de andere.

Soft, ~20 ronden levensduur
Hard, ~35 ronden levensduur
Soft start ~1,2s snellerMeer grip, lagere basis rondetijd op verse banden
Soft slijt snellerOngeveer 0,10s/ronde vs 0,04s/ronde op hard
Soft "cliff" bij ronde 19Voorbij de levensduur stijgt de lijn scherp
Hard bereikt zijn cliff nietBinnen een 55-ronde race kan hard makkelijk 35+ ronden
