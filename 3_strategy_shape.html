Hoeveel pit stops?

We tellen de rondetijden op voor elke mogelijke wedstrijdvorm. De nullijn bovenaan is de "perfecte" basisronde — geen brandstof, geen bandenslijtage, geen pit stops. Onmogelijk in een echte race, maar nuttig als ijklat. Elke lijn toont hoeveel seconden je verliest t.o.v. die ideale ronde. Hoogste lijn op het einde wint.

Toon:
No-stop lijn = brandstofverlies + bandenslijtage zónder pit stops · One/Two-stop = idem + 22s per pit stop
No-stop (illegaal): hard tyre 55 ronden, geen pit verliezen
One-stop, soft → hard (L21)
Two-stop, soft → hard → hard (L17 + L37)
Beslissing: one-stop, soft → hard. Nu nog kiezen op welke ronde we stoppen.
